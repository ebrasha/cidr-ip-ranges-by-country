このリポジトリには、すべての国におけるIPv4およびIPv6のCIDR IP範囲が収録されています。国別に整理された包括的で最新のIP範囲リストを提供することで、ネットワーク管理やジオロケーションサービスなどを円滑に進めることを目的としています。
💨 このリポジトリは1時間ごとに更新されます
## ✨ 目次

- IPv4 CIDR IP範囲
- IPv6 CIDR IP範囲

## ✨ 構成

リポジトリは国別に整理されており、各国にそれぞれディレクトリが用意されています。各ディレクトリ内には2つのファイルが存在します：
- `*-ipv4-Hackers.Zone.txt`：IPv4のCIDR範囲が記載されています。
- `*-ipv6-Hackers.Zone.txt`：IPv6のCIDR範囲が記載されています。

## 📝️ 使い方

特定の国のCIDR IP範囲を利用するには、該当する国のディレクトリに移動し、適切なファイル（`*-ipv4-Hackers.Zone.tx`または`*-ipv6-Hackers.Zone.txt`）を選択してください。
