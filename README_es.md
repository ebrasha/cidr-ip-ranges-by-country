Este repositorio contiene rangos CIDR de IP para IPv4 e IPv6 de todos los países. Su objetivo es ofrecer una lista completa y actualizada de rangos de IP organizados por país, lo que facilita la gestión de redes, los servicios de geolocalización y más.
 💨 Este repositorio se actualiza cada hora
## ✨ Contenido

- Rangos CIDR de IP IPv4
- Rangos CIDR de IP IPv6

## ✨ Estructura

El repositorio está organizado por país, siendo cada país su propio directorio. Dentro de cada directorio, encontrará dos archivos:
- `*-ipv4-Hackers.Zone.txt`: Contiene los rangos CIDR de IPv4.
- `*-ipv6-Hackers.Zone.txt`: Contiene los rangos CIDR de IPv6.

## 📝️ Uso

Para utilizar los rangos CIDR de IP de un país específico, vaya al directorio correspondiente al país y seleccione el archivo adecuado (`*-ipv4-Hackers.Zone.tx` o `*-ipv6-Hackers.Zone.txt`).
