# بازه‌های آدرس IP بر اساس کشور - بازه‌های CIDR IP بر اساس کشور

> 🌐 **به زبان خودتان بخوانید:** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

این مخزن شامل بازه‌های IP به‌صورت CIDR برای IPv4 و IPv6 همه کشورها است. هدف آن ارائه فهرستی جامع و به‌روز از بازه‌های IP، سازمان‌یافته بر اساس کشور، برای تسهیل مدیریت شبکه، سرویس‌های مکان‌یابی جغرافیایی و موارد مشابه است.
 💨 این مخزن هر ساعت به‌روزرسانی می‌شود
## ✨ محتوا

- بازه‌های IP به‌صورت CIDR برای IPv4
- بازه‌های IP به‌صورت CIDR برای IPv6

## ✨ ساختار

این مخزن بر اساس کشور سازمان‌دهی شده و هر کشور پوشه مخصوص خود را دارد. داخل هر پوشه دو فایل خواهید یافت:
- `*-ipv4-Hackers.Zone.txt`: شامل بازه‌های CIDR مربوط به IPv4.
- `*-ipv6-Hackers.Zone.txt`: شامل بازه‌های CIDR مربوط به IPv6.

## 📝️ نحوه استفاده

برای استفاده از بازه‌های IP به‌صورت CIDR مربوط به یک کشور خاص، به پوشه همان کشور بروید و فایل مناسب را انتخاب کنید (`*-ipv4-Hackers.Zone.tx` یا `*-ipv6-Hackers.Zone.txt`).
