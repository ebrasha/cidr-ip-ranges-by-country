# IP-Adressbereiche nach Land - CIDR-IP-Bereiche nach Land

Dieses Repository enthält CIDR-IP-Bereiche für IPv4 und IPv6 aller Länder. Ziel ist es, eine umfassende und aktuelle Liste von IP-Bereichen – organisiert nach Ländern – bereitzustellen und so Netzwerkverwaltung, Geolocation-Dienste und mehr zu erleichtern.
 💨 Dieses Repository wird stündlich aktualisiert
## ✨ Inhalt

- IPv4-CIDR-IP-Bereiche
- IPv6-CIDR-IP-Bereiche

## ✨ Struktur

Das Repository ist nach Ländern organisiert; jedes Land hat ein eigenes Verzeichnis. In jedem Verzeichnis finden Sie zwei Dateien:
- `*-ipv4-Hackers.Zone.txt`: Enthält die IPv4-CIDR-Bereiche.
- `*-ipv6-Hackers.Zone.txt`: Enthält die IPv6-CIDR-Bereiche.

## 📝️ Verwendung

Um die CIDR-IP-Bereiche eines bestimmten Landes zu verwenden, öffnen Sie das entsprechende Länderverzeichnis und wählen Sie die passende Datei (`*-ipv4-Hackers.Zone.tx` oder `*-ipv6-Hackers.Zone.txt`).
