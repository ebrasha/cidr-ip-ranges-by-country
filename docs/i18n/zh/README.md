# 按国家划分的 IP 地址范围 - 各国 CIDR IP 范围

> 🌐 **选择您的语言：** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

本仓库包含世界各国的 IPv4 与 IPv6 CIDR IP 地址段。目标是提供一份按国家整理、全面且持续更新的 IP 地址段列表，便于网络管理、地理位置服务等场景使用。
 💨 本仓库每小时更新一次
## ✨ 内容

- IPv4 CIDR IP 地址段
- IPv6 CIDR IP 地址段

## ✨ 结构

仓库按国家组织，每个国家对应一个目录。在每个目录中，您会找到两个文件：
- `*-ipv4-Hackers.Zone.txt`：包含 IPv4 CIDR 地址段。
- `*-ipv6-Hackers.Zone.txt`：包含 IPv6 CIDR 地址段。

## 📝️ 用法

若要使用特定国家的 CIDR IP 地址段，请进入对应国家的目录，并选择合适的文件（`*-ipv4-Hackers.Zone.tx` 或 `*-ipv6-Hackers.Zone.txt`）。
