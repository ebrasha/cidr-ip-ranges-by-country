# देशवार IP पता श्रेणियाँ - देशवार CIDR IP श्रेणियाँ

> 🌐 **अपनी भाषा में पढ़ें:** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

इस रिपॉज़िटरी में सभी देशों के लिए IPv4 और IPv6 के CIDR IP रेंज शामिल हैं। इसका उद्देश्य देशवार व्यवस्थित, व्यापक और अद्यतन IP रेंज सूची प्रदान करना है, ताकि नेटवर्क प्रबंधन, जियोलोकेशन सेवाएँ और अन्य उपयोग आसान हो सकें।
 💨 यह रिपॉज़िटरी हर घंटे अपडेट होती है
## ✨ सामग्री

- IPv4 CIDR IP रेंज
- IPv6 CIDR IP रेंज

## ✨ संरचना

रिपॉज़िटरी को देशों के अनुसार व्यवस्थित किया गया है; प्रत्येक देश की अपनी निर्देशिका है। प्रत्येक निर्देशिका में आपको दो फ़ाइलें मिलेंगी:
- `*-ipv4-Hackers.Zone.txt`: इसमें IPv4 CIDR रेंज हैं।
- `*-ipv6-Hackers.Zone.txt`: इसमें IPv6 CIDR रेंज हैं।

## 📝️ उपयोग

किसी विशिष्ट देश के CIDR IP रेंज उपयोग करने के लिए संबंधित देश की निर्देशिका में जाएँ और उपयुक्त फ़ाइल चुनें (`*-ipv4-Hackers.Zone.tx` या `*-ipv6-Hackers.Zone.txt`)।
