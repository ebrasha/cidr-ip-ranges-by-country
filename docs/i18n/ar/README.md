# نطاقات عناوين IP حسب الدولة - نطاقات CIDR IP حسب الدولة

> 🌐 **اقرأ بلغتك:** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

يحتوي هذا المستودع على نطاقات عناوين IP بصيغة CIDR لإصداري IPv4 وIPv6 لجميع الدول. ويهدف إلى توفير قائمة شاملة ومحدَّثة لنطاقات IP مرتبة حسب الدولة، بما يسهّل إدارة الشبكات وخدمات تحديد الموقع الجغرافي وغيرها.
 💨 يتم تحديث هذا المستودع كل ساعة
## ✨ المحتويات

- نطاقات IP بصيغة CIDR لإصدار IPv4
- نطاقات IP بصيغة CIDR لإصدار IPv6

## ✨ البنية

المستودع منظم حسب الدولة، ولكل دولة مجلد خاص بها. داخل كل مجلد ستجد ملفين:
- `*-ipv4-Hackers.Zone.txt`: يحتوي على نطاقات CIDR لإصدار IPv4.
- `*-ipv6-Hackers.Zone.txt`: يحتوي على نطاقات CIDR لإصدار IPv6.

## 📝️ الاستخدام

لاستخدام نطاقات IP بصيغة CIDR لدولة معيّنة، انتقل إلى مجلد تلك الدولة واختر الملف المناسب (`*-ipv4-Hackers.Zone.tx` أو `*-ipv6-Hackers.Zone.txt`).
