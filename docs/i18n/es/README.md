# Rangos de direcciones IP por país - Rangos IP CIDR por país

> 🌐 **Leer en tu idioma:** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

Este repositorio contiene rangos IP CIDR de IPv4 e IPv6 para todos los países. Su objetivo es ofrecer una lista completa y actualizada de rangos IP organizados por país, facilitando la gestión de redes, los servicios de geolocalización y más.
 💨 Este repositorio se actualiza cada hora
## ✨ Contenido

- Rangos IP CIDR IPv4
- Rangos IP CIDR IPv6

## ✨ Estructura

El repositorio está organizado por país; cada país tiene su propio directorio. Dentro de cada directorio encontrarás dos archivos:
- `*-ipv4-Hackers.Zone.txt`: Contiene los rangos CIDR IPv4.
- `*-ipv6-Hackers.Zone.txt`: Contiene los rangos CIDR IPv6.

## 📝️ Uso

Para usar los rangos IP CIDR de un país concreto, ve al directorio correspondiente y selecciona el archivo adecuado (`*-ipv4-Hackers.Zone.tx` o `*-ipv6-Hackers.Zone.txt`).
