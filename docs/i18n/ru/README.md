# Диапазоны IP-адресов по странам - CIDR IP-диапазоны по странам

> 🌐 **Читайте на своем языке:** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

Этот репозиторий содержит CIDR-диапазоны IP-адресов IPv4 и IPv6 для всех стран. Его цель — предоставить полный и актуальный список IP-диапазонов, организованный по странам, для удобства управления сетями, сервисов геолокации и других задач.
 💨 Этот репозиторий обновляется каждый час
## ✨ Содержание

- CIDR-диапазоны IPv4
- CIDR-диапазоны IPv6

## ✨ Структура

Репозиторий организован по странам: у каждой страны есть собственный каталог. Внутри каждого каталога вы найдёте два файла:
- `*-ipv4-Hackers.Zone.txt`: содержит CIDR-диапазоны IPv4.
- `*-ipv6-Hackers.Zone.txt`: содержит CIDR-диапазоны IPv6.

## 📝️ Использование

Чтобы использовать CIDR IP-диапазоны для конкретной страны, перейдите в каталог этой страны и выберите нужный файл (`*-ipv4-Hackers.Zone.tx` или `*-ipv6-Hackers.Zone.txt`).
