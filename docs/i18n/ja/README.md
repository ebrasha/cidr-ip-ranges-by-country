# 国別 IP アドレス範囲 - 国別 CIDR IP 範囲

> 🌐 **言語を選択してください：** 🇬🇧 [English](../../../README.md) | 🇨🇳 [中文](../zh/README.md) | 🇷🇺 [Русский](../ru/README.md) | 🇪🇸 [Español](../es/README.md) | 🇯🇵 [日本語](../ja/README.md) | 🇮🇷 [فارسی](../fa/README.md) | 🇸🇦 [العربية](../ar/README.md) | 🇹🇷 [Türkçe](../tr/README.md) | 🇩🇪 [Deutsch](../de/README.md) | 🇮🇳 [हिन्दी](../hi/README.md)

このリポジトリには、各国の IPv4 / IPv6 CIDR IP 範囲が含まれています。国別に整理された包括的で最新の IP 範囲リストを提供し、ネットワーク管理やジオロケーションサービスなどへの活用を目的としています。
 💨 このリポジトリは1時間ごとに更新されます
## ✨ 内容

- IPv4 CIDR IP 範囲
- IPv6 CIDR IP 範囲

## ✨ 構成

リポジトリは国ごとに整理されており、各国ごとに専用のディレクトリがあります。各ディレクトリ内には次の2つのファイルがあります：
- `*-ipv4-Hackers.Zone.txt`：IPv4 CIDR 範囲を含みます。
- `*-ipv6-Hackers.Zone.txt`：IPv6 CIDR 範囲を含みます。

## 📝️ 使い方

特定の国の CIDR IP 範囲を使用するには、該当する国のディレクトリに移動し、適切なファイル（`*-ipv4-Hackers.Zone.tx` または `*-ipv6-Hackers.Zone.txt`）を選択してください。
