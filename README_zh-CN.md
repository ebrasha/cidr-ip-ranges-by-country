# 各国IP地址范围——按国家分类的CIDR IP范围

该仓库收录了所有国家的IPv4和IPv6 CIDR IP范围。它旨在提供按国家整理的、全面且最新的IP范围列表，从而助力网络管理、地理定位服务等相关工作。
💨 该仓库每小时更新一次
## ✨ 目录结构

- IPv4 CIDR IP范围
- IPv6 CIDR IP范围

## ✨ 文件结构

该仓库是按国家分类组织的，每个国家都有独立的目录。在每个目录中，您会找到两个文件：
- `*-ipv4-Hackers.Zone.txt`：包含IPv4 CIDR范围。
- `*-ipv6-Hackers.Zone.txt`：包含IPv6 CIDR范围。

## 📝️ 使用方法

如需使用特定国家的CIDR IP范围，请进入 해당国家的目录并选择对应的文件（`*-ipv4-Hackers.Zone.tx` 或 `*-ipv6-Hackers.Zone.txt`）。
